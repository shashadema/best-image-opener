原图助手 · 安装与使用说明
版本 1.0.7（2026-11-10）
================================

一句话：在图片上右键 →「打开原图（新标签页）」，尽量拿到这张图能拿到的最高画质版本。

这是一个本地 Chrome / Edge 扩展，不需要上架商店，也不需要注册账号。
所有处理都在你本机完成：不收集、不上传任何数据。

一、安装（约 30 秒）
----------------
1. 解压收到的 zip。
2. Chrome 地址栏输入：chrome://extensions
   （Edge 输入 edge://extensions）
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」。
5. 选择解压出来的 best-image-opener 文件夹
   —— 必须是里面能直接看到 manifest.json 的那一层，不要选 src 子目录。
   —— 文件夹英文名是内部名，不影响使用。
6. 装好后，把工具栏上的「原图助手」图标固定出来，方便随时开关。

Chrome 会提示「开发者模式扩展」，这是本地安装的正常提示，不是报错。

二、怎么用
----------------
- 图片上右键 →「打开原图（新标签页）」
-「复制原图地址」「下载原图」也在同一个子菜单里
- 背景图、透明覆盖层上的图片同样可以右键
- 按住 Alt 再右键：跳过扩展，使用网站自己的右键菜单
- 点工具栏图标：可对当前网站单独停用，或调整常用开关

三、支持的站点
----------------
微博/新浪图床、知乎、B站、淘宝/天猫、京东、小红书、豆瓣、花瓣网、
X/Twitter、Pinterest、Pixiv、微信公众号、Wikipedia、Google 相册、
Imgur、Medium、Substack、ArtStation。

其他网站也会自动尝试：srcset、<picture>、懒加载属性、外层大图链接、
CSS 背景图，以及 x-oss-process / imageView2 这类常见缩放参数。

四、图片打不开怎么办
----------------
- Instagram、Facebook、抖音等签名 CDN：地址和签名绑定，改一个字符就 403，
  扩展会保留原地址，这是正常行为。
- 小红书：会自动解析成公开原图地址，优先返回高清 JPEG（不再是网页里的 webp 压缩图）；
  解析失败时会退回页面当前的签名地址，保证至少能打开。
- 微博：已自动带上来源页 Referer，防盗链站点可以正常打开；
  个别老图没有 oslarge 尺寸时会自动回退到其他可用尺寸。
- 第一次右键某张图时，Chrome 菜单里可能出现自带的「加载图片」，
  那是 Chrome 在加载临时代理图，不影响使用，再右键一次通常会消失。
- 如果某张图仍然打不开，可以用「复制图片地址」拿到地址后直接用浏览器访问，
  用来判断是不是网站本身不允许外链。

五、卸载
----------------
chrome://extensions → 找到「原图助手」→ 点「移除」。
